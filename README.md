# FIFA-dashboard
FIFA WORLD CUP ANALYSIS (1930-2014) DASHBOARD
This Power BI dashboard provides an in-depth analysis of FIFA World Cup data, covering 20 tournaments, 352 matches, and 2379 total goals. It includes key metrics like the number of World Cups won by countries, match statistics, and player performance insights. The dashboard features interactive filters for home teams, cities, and match start times to explore data dynamically. Ideal for football enthusiasts and analysts, it uncovers trends and historical patterns in World Cup history.
